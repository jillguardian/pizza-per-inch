# Security policy

## What is covered

The live site, <https://jillguardian.github.io/pizza-per-inch/>, and the latest version of the code on `main`. There are no releases and no older supported versions.

The app has no server, no accounts and no stored data: everything a visitor types stays in their browser. The things worth reporting are a weakness in the app itself or in one of its dependencies.

## How to report a problem

Please report it privately, so it is not public before it is fixed:

1. Open the [Security tab](https://github.com/jillguardian/pizza-per-inch/security) of the repository.
2. Choose **Report a vulnerability**, and describe what you found and how to reproduce it.

Please do not open a public issue for a security problem.

## What to expect

This is a one-person project, so replies are best effort and there is no fixed response time. A confirmed problem is fixed on `main`, and the report is closed with a note on what changed.
